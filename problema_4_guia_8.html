Péndulo simple: del potencial U(θ) al método de Euler

Se parte del potencial y de la energía, se llega a la ecuación de movimiento y se la integra numéricamente. La animación calcula todo en el navegador y compara la solución de Euler con una referencia precisa.

1. Repaso de (a) y (b): potencial y tipos de movimiento

El potencial está definido a menos de una constante. Elegimos el cero a la altura del punto de suspensión, de modo que

U(θ) = −m g l cos θ   ⇒   Um = −m g l en θ = 0 (equilibrio estable),   UM = +m g l en θ = ±π (equilibrio inestable)

La energía mecánica se conserva, E0 = T + U = ½m l² θ² − m g l cos θ, y de ahí sale la velocidad a partir del gráfico de U:

θ² = 2E0/(m l²) + (2g/l) cos θ   ⇒   θ(θ) = ± √( 2 [E0 − U(θ)] / (m l²) )   (solo hay movimiento donde E0 ≥ U)
CasoMovimientoCómo conseguirlo en la práctica
Energía mínima
Em = Um = −m g l		 θ² = (2g/l)(cos θ − 1) ≥ 0 solo se cumple en θ = 0, así que θ ≡ 0 y θ ≡ 0 para todo t: equilibrio estable. Dejar la masa en reposo en la vertical.
E1 intermedia
Um < E1 < UM		 Oscilación entre −θR y +θR. Por ejemplo con E1 = 0: θ² = (2g/l) cos θ, y los puntos de retorno (θ = 0) son θR = ±π/2. Apartar la masa un ángulo θR < π y soltarla sin impulso: E1 = −m g l cos θR.
E2 al borde
E2 = UM = m g l		 θ² = (2g/l)(cos θ + 1): la velocidad se anula solo en θ = ±π. La masa se acerca al tope cada vez más despacio y tarda un tiempo infinito en llegar. Es un equilibrio inestable. Desde θ = 0, lanzar con θ0 = 2√(g/l), es decir v0 = 2√(g l). La varilla rígida permite llegar hasta arriba.
E3 mayor al borde
E3 > UM		 Rotación. Por ejemplo con E3 = 2m g l: θ² = (2g/l)(cos θ + 2) > 0 para todo θ, así que θ nunca se anula y la masa da vueltas siempre en el mismo sentido. Desde θ = 0, lanzar con v0 > 2√(g l). Para E3 = 2m g l: θ0 = √6 √(g/l).

2. Parte (c): el método de Euler

Para amplitudes grandes ya no vale sen θ ≈ θ y la ecuación no tiene solución elemental:

θ = −(g/l) sen θ
  1. Bajar el orden. Se define ω = θ y queda un sistema de primer orden:
    θ = ω     ω̇ = −(g/l) sen θ
  2. Un paso de Euler. Se desarrolla en Taylor alrededor de tn:
    θ(tn + h) = θn + h ωn + ½ h² θn + O(h³)
    Euler se queda con los dos primeros términos, y lo mismo para ω:
    θn+1 = θn + h ωn
    ωn+1 = ωn − h (g/l) sen θn
  3. Error. Lo que se descarta es ½ h² θn, así que el error de cada paso es O(h²). Para llegar de t0 a tf hacen falta N = (tf − t0)/h pasos, y el error acumulado es del orden de N · h² = O(h).
  4. Repetir. Con (θ0, ω0) como condiciones iniciales se obtiene la sucesión (tn, θn, ωn) que se grafica.

¿Por qué la energía crece en cada paso? Cerca del equilibrio, U ≈ −m g l + ½m g l θ², y con ω0² = g/l la energía medida desde el fondo del pozo es E + m g l ≈ ½m l² (ω² + ω0² θ²). Aplicando un paso de Euler:

ω0² θn+1² + ωn+1² = ω0² (θn + h ωn)² + (ωn − h ω0² θn)²
                                = (1 + ω0² h²) (ω0² θn² + ωn²)   (los términos cruzados ±2hω0² θn ωn se cancelan)

Es decir, (E + m g l)n+1 = (1 + ω0² h²) (E + m g l)n, con un factor siempre mayor que 1: cada paso agrega energía, por chico que sea h. En la animación se ve cómo sube la línea de E y, si cruza UM, el péndulo deja de oscilar y empieza a girar. Eso es un artefacto del método y no física.

Existen métodos mejores que no tienen este problema. Si quieren chusmear: Euler semi-implícito (Euler–Cromer), Runge–Kutta, Verlet y integradores simplécticos. En la animación, la línea punteada gris de referencia está calculada con Runge–Kutta de 4.º orden y paso fino.

4. Qué observar

  1. Los cuatro botones de energía. En el gráfico de U y E, la línea horizontal de E muestra hasta dónde puede llegar la masa (los círculos son los puntos de retorno). En θ(t) y θ(t) se ve la oscilación (E1), el movimiento límite (E2) y la rotación (E3: θ crece sin parar y θ nunca se anula).
  2. Euler contra la referencia. La curva sólida se va separando de la punteada y la línea de E sube. Con h más chico pasa más tarde y con h más grande pasa antes. Con E2 el péndulo de Euler termina girando aunque la energía inicial sea justo UM. Incluso la referencia termina cayendo para un lado: llegar al tope lleva un tiempo infinito y el error numérico más chico decide si el péndulo pasa de largo o vuelve.
  3. Amplitud pequeña y grande. Con amplitud pequeña θ(t) es casi una senoide. Con amplitud grande la curva se achata y el período es más largo.

5. Para implementarlo en Python

Script completo (NumPy, SciPy y Matplotlib). Integra con Euler, compara con una referencia de alta precisión (solve_ivp) y grafica U(θ) con la energía, θ(t) y θ(t). Para ver cómo cambia el resultado, probar distintos valores de step en CONFIG.

pendulum_euler.py 
"""Simple pendulum integrated with Euler's method."""

import matplotlib.pyplot as plt
import numpy as np
from scipy.integrate import solve_ivp

G = 9.81  # gravity [m/s^2]
LENGTH = 1.0  # rod length [m]


def euler(
    theta0: float,
    omega0: float,
    step: float,
    t_total: float,
) -> tuple[np.ndarray, np.ndarray, np.ndarray]:
    """
    Integrates the pendulum with Euler's method.

    The equation `theta'' = -(g/l) sin(theta)` is rewritten as the
    first-order system `theta' = omega`, `omega' = -(g/l) sin(theta)`.

    Parameters
    ----------
    theta0 : float
        Initial angle [rad].
    omega0 : float
        Initial angular velocity [rad/s].
    step : float
        Time step `h` [s].
    t_total : float
        Total simulated time [s].

    Returns
    -------
    tuple[np.ndarray, np.ndarray, np.ndarray]
        Time, angle and angular velocity arrays.
    """
    n_steps = int(round(t_total / step))
    time = step * np.arange(n_steps + 1)
    theta = np.empty(n_steps + 1)
    omega = np.empty(n_steps + 1)
    theta[0], omega[0] = theta0, omega0
    for i in range(n_steps):
        theta[i + 1] = theta[i] + step * omega[i]
        omega[i + 1] = omega[i] - step * G / LENGTH * np.sin(theta[i])
    return time, theta, omega


def potential(theta: np.ndarray) -> np.ndarray:
    """
    Potential energy in units of `m g l`.

    Parameters
    ----------
    theta : np.ndarray
        Angle [rad].

    Returns
    -------
    np.ndarray
        `U / (m g l) = -cos(theta)`, so `U_m = -1` and `U_M = 1`.
    """
    return -np.cos(theta)


def energy(theta: np.ndarray, omega: np.ndarray) -> np.ndarray:
    """
    Mechanical energy in units of `m g l`.

    Parameters
    ----------
    theta : np.ndarray
        Angle [rad].
    omega : np.ndarray
        Angular velocity [rad/s].

    Returns
    -------
    np.ndarray
        `E / (m g l) = 0.5 * omega**2 * l / g - cos(theta)`.
    """
    return 0.5 * omega**2 * LENGTH / G + potential(theta)


def solve_reference(
    theta0: float,
    omega0: float,
    time: np.ndarray,
) -> tuple[np.ndarray, np.ndarray]:
    """
    High-accuracy solution (adaptive Runge-Kutta) used as reference.

    Parameters
    ----------
    theta0 : float
        Initial angle [rad].
    omega0 : float
        Initial angular velocity [rad/s].
    time : np.ndarray
        Times at which the solution is evaluated [s].

    Returns
    -------
    tuple[np.ndarray, np.ndarray]
        Angle and angular velocity at `time`.
    """
    solution = solve_ivp(
        lambda _, y: [y[1], -G / LENGTH * np.sin(y[0])],
        (time[0], time[-1]),
        [theta0, omega0],
        t_eval=time,
        rtol=1e-10,
        atol=1e-12,
    )
    return solution.y[0], solution.y[1]


def plot_solution(
    time: np.ndarray,
    theta: np.ndarray,
    omega: np.ndarray,
    reference: tuple[np.ndarray, np.ndarray],
) -> None:
    """
    Plots U(theta) with the energy, theta(t) and omega(t).

    Parameters
    ----------
    time : np.ndarray
        Time samples [s].
    theta : np.ndarray
        Euler angle [rad].
    omega : np.ndarray
        Euler angular velocity [rad/s].
    reference : tuple[np.ndarray, np.ndarray]
        Reference angle and angular velocity.
    """
    theta_ref, omega_ref = reference
    _, (ax_energy, ax_theta, ax_omega) = plt.subplots(1, 3, figsize=(14, 4))

    grid = np.linspace(-2 * np.pi, 2 * np.pi, 400)
    euler_energy = energy(theta, omega)
    ax_energy.plot(grid, potential(grid), label="U(theta)")
    ax_energy.axhline(1.0, color="r", linestyle=":", label="U_M")
    ax_energy.axhline(
        euler_energy[0], color="gray", linestyle="--", label="E initial"
    )
    ax_energy.axhline(
        euler_energy[-1], color="k", linestyle="-.", label="E final (Euler)"
    )
    ax_energy.set(xlabel="theta [rad]", ylabel="U, E  [m g l]")

    ax_theta.plot(time, theta, label="Euler")
    ax_theta.plot(time, theta_ref, "--", label="reference")
    ax_theta.set(xlabel="t [s]", ylabel="theta [rad]")

    ax_omega.plot(time, omega, label="Euler")
    ax_omega.plot(time, omega_ref, "--", label="reference")
    ax_omega.set(xlabel="t [s]", ylabel="omega [rad/s]")

    for ax in (ax_energy, ax_theta, ax_omega):
        ax.legend()
    plt.tight_layout()


def main(
    theta0_deg: float,
    omega0: float,
    step: float,
    t_total: float,
) -> None:
    """
    Runs Euler's method for the pendulum and plots the results.

    Parameters
    ----------
    theta0_deg : float
        Initial angle [deg].
    omega0 : float
        Initial angular velocity [rad/s].
    step : float
        Euler time step [s].
    t_total : float
        Total simulated time [s].
    """
    theta0 = np.radians(theta0_deg)
    time, theta, omega = euler(theta0, omega0, step, t_total)
    reference = solve_reference(theta0, omega0, time)
    plot_solution(time, theta, omega, reference)
    plt.show()


if __name__ == "__main__":
    CONFIG = {
        "theta0_deg": 90.0,
        "omega0": 0.0,
        "step": 0.01,
        "t_total": 30.0,
    }
    main(**CONFIG)
